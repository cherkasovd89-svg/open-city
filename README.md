# OPEN CITY

Небольшой браузерный 3D-прототип городского экшена на Three.js.

## Управление
- WASD / стрелки — движение
- Shift / кнопка «БЕГ» — бег
- Свайп по экрану или мышь — вращение камеры
- E / кнопка «АВТО» — сесть в ближайшую машину или выйти

Открой игру по адресу GitHub Pages после успешного запуска workflow.

Это игровой прототип, а не полноценная GTA. Для загрузки Three.js требуется интернет-соединение.

# Enchanted Vale — 2D Android Metroidvania

A new Godot 4 fantasy side-scrolling game prototype is being developed in this repository alongside the original Open City browser prototype.

## Open the game
Open the repository root in Godot 4.3 or newer and run `scenes/main.tscn`.

## Prototype features
- Side-view fantasy hero with running, jumping, sword swing and dodge.
- Platform collision and a first forest route.
- Procedural twilight background, layered distant hills, glowing particles and stylized platform/enemy silhouettes.
- On-screen joystick and action buttons.
- Touch controls hide when a physical gamepad is connected; keyboard and gamepad actions are mapped.

## Development status
Early foundation only. The current visuals are procedural placeholders. Original illustrated character sheets, detailed environment art, enemy AI, room transitions, progression, save system and Android export configuration are still to be added and tested.
